# 5min Finance (POC)

Stay on top of your savings buckets/goals and retirement funds across multiple accounts.

This is an app version of a spreadsheet I've been using for 10+ years, taking me only 5 minutes a month to update.

Technical details
- Stack: Laravel, Filament, Livewire, SQLite, Tailwind, Vite.
- Github Actions CI with automated tests and linting.
- Claude Code for AI development and PR reviews.
- Deployed to an AWS EC2 Ubuntu server.
